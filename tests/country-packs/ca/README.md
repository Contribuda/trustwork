# Canada pack evidence and verification

CTRY-CA adds a **partial** v2 pack, not an operational Canadian hub or legal approval. The source of truth is [`ca.json`](../../../packages/country-packs/packs/ca.json). Source access dates are **2026-11-01 UTC**. Each facet fact carries its own source, level and, where needed, limitations; `official` describes the specific sourced statement, not an entity verification or permission to activate an integration.

## Verification coverage

`node --import tsx --test tests/country-packs/ca/ca.test.ts` covers v2 validation, registry integration, a generated v1 client projection without server facts/sources, regions, `Intl` en-CA/fr-CA and CAD, postal/identifier negative cases, IANA local exceptions, province-isolated facts, tax overrides without double GST/HST, nominal holidays, bounded procurement thresholds, dated official-host sources, restricted-subdivision rejection and absence of Canada branches or Russian providers.

The complete country-pack suite also checks the generic schema, validators, registries, layers and helpers. No live company lookup, payment, tax computation, provider call or UI/browser acceptance is claimed. Full repository checks run in CI under the conductor's LOAD RULE.

## Follow-ups and conservative defaults

- Install and review LANG-FR dictionaries before enabling `fr`. Existing `Intl` helpers already format `fr-CA`; the current pack enables only English. A Quebec hub must configure French as its default when those dictionaries exist. Schema v2 has no subdivision-level `defaultLocale`, so this pack does not invent an automatic province-specific language switch.
- Complete provincial/territorial corporation-number formats, contractor licence classes, permits, adopted code editions, privacy applicability and other provincial procurement portals before relying on them. The pack is deliberately `partial`.
- All calendar facts have `nonWorking: false` and `observed: none`. These fields prevent a national calendar from declaring every construction site closed; they do not deny statutory entitlements. A hub needs workplace coverage, substitution and collective-agreement rules. Good Friday, Victoria Day and National Patriots Day have only reviewed 2026 dates.
- Pending e-invoicing booleans are schema-required placeholders, explicitly not legal conclusions. Do not activate tax, signing, procurement or register adapters from these facts; no adapter is implemented here.
- Federal and Quebec electronic-signature, prompt-payment, privacy and agent-law applicability need counsel review. Legal template keys are references, not approved legal documents; HUB-005 and hub launch gates remain necessary.
- Facets are server data. Regenerate the package's v1 client projection when a built-in pack changes; client-only code must use `@trustwork/country-packs/client`.
