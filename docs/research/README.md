# Research notes

Point-in-time research and audits that inform planning. A note here is **evidence and proposals, not decisions**: nothing in this folder changes a rule, a contract or the work-package list by itself. Accepted conclusions move into an ADR, the handbook (`docs/engine/`) or `docs/engine/work-packages.json` through their own pull requests.

Conventions: each note names the commit it examined, separates measured facts from judgement, cites `path:line` evidence, and lists open questions for the owner instead of guessing.
