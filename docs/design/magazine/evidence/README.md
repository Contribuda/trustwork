# CNT-003 local acceptance evidence

These artifacts use a real local API, embedded PostgreSQL, the HTTP DataPort, a production Next build and installed Chromium. All participants and content are explicitly synthetic. No provider, real user, remote font or network asset is involved. The PR result report identifies the exact checked commit and command exit codes.

## Reader

The bounded browser script is `tests/web/content/live.ts`. It checks nine public surfaces in all seven engine languages at 375 px: news list/detail, article list/detail, magazine home, issue, archive, rubric and reader. It checks response status, horizontal overflow, inert content, absence of the private draft, keyboard focus and axe WCAG A/AA results. It also checks the reader contents dialog by keyboard, nine feed endpoints, correction JSON-LD, the owner's private workspace and a real worker PDF downloaded through the web origin and its visible desktop link. Automated checks do not establish manual screen-reader acceptance.

## PDF page-by-page inspection

The [two-page Russian artifact](issue-live-ru.pdf) was generated by the registered worker from the released revision and persisted by the guarded database completion function. Poppler rendered both pages for visual inspection:

- [Page 1](issue-live-ru-page-1.png): localized issue/edition/date, synthetic title, contents, pinned revision and digest; no clipping, overlap or missing glyphs.
- [Page 2](issue-live-ru-page-2.png): public author credit, pinned version, actual correction note, separate AI-assistance disclosure, inert article text and page number; no clipping, overlap or missing glyphs.

The PDF has A4 pages, tagging, no JavaScript and no remote assets. This is a page-by-page visual review, not PDF/UA certification or a manual screen-reader review. The separate persistence regression also renders and inspects a two-page corrected Russian artifact when `CNT003_EVIDENCE_DIR` is set. Without that flag its portable database test uses an explicitly synthetic renderer; that mode alone is not PDF-layout acceptance.

## Reproduction

Use the installed dependencies and Chromium; do not install providers or fetch browser assets. Run one test process at a time:

```sh
TRUSTWORK_API_ORIGIN=http://127.0.0.1:3467 NEXT_TELEMETRY_DISABLED=1 NODE_OPTIONS=--max-old-space-size=2048 npm run build -w @trustwork/web
TRUSTWORK_TEST_PG_BACKEND=embedded TRUSTWORK_REQUIRE_PG=1 CNT003_EVIDENCE_DIR=/absolute/evidence/path node --import tsx tests/web/content/live.ts
```

The complete local report, 63 page screenshots, axe reports, feed bodies and browser error reports are retained in the conductor handoff directory `cnt003-evidence`. The PR preserves historical failed attempts and the bounded isolated keyboard retry rather than erasing them. Missing accepted public provenance, manual screen-reader review and production packaging boundaries are described in [reader boundaries](../CNT-003-reader-boundaries.md).
