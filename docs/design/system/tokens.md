# Design tokens

Status: **proposed canonical, revised by DS-002 (visual quality pass, 2026-10-27).** DS-001 promoted the DS-000 proposal; DS-002 adds the tonal blue scale, the warm canvas, the editorial type scale, elevation, scrims and motion described in [art-direction.md](art-direction.md). Human visual acceptance (O09) is separate from these engineering checks.

## Source of truth and build

- `packages/ui/tokens/index.ts` is the single source (typed exports: `blue`, `color`, `scrim`, `space`, `section`, `font`, `weight`, `type`, `radius`, `shadow`, `zIndex`, `breakpoint`, `mediaQuery`, `focus`, `motion`, `size`, plus `tokens`).
- `packages/ui/tokens/tokens.css` is generated by `npm run tokens:build -w @trustwork/ui` and committed; `tests/unit/tokens.test.ts` fails if the two diverge and checks every contrast pair below.
- `packages/ui/tokens.css` (package root, legacy path) re-exports the generated file.
- Light theme only. All values live on `:root, [data-theme="light"]`; a dark theme would add a `[data-theme="dark"]` block with the same custom-property names. Components reference roles, never hex values.

Import order in an application: `@trustwork/ui/tokens.css`, `@trustwork/ui/fonts.css`, then `@trustwork/ui/base.css` (reset, focus ring, typography utilities, container/grid/section rhythm, enter animation, reduced motion, scroll padding).

## Blue scale

`--blue-50` `#f0f5ff`, `100` `#e6eefc`, `200` `#b7cdf5`, `300` `#8db2ef`, `400` `#5b93f0`, `500` `#1a6ee8` (brand mark), `600` `#0756d8` (UI accent), `700` `#0648b4`, `800` `#053c96`, `900` `#0f1f3d` (navy). The scale darkens monotonically (unit test).

| Token | Value | Use |

| `--scrim-left` | navy 0.9 → 0.78 @42 % → 0.1 (90deg) | 21:9 lead hero |

| `--scrim-text` | navy 0 → 0.78 over `--scrim-fade` (48 px default, 56 px in overlays, 72 px in the auth panel), then constant | Text-anchored layer on overlay blocks |

Unit test: white over navy at alpha 0.78 composited on pure white = 8.3:1; `navyTextMuted` also passes. Playwright `contrast.spec.ts` samples rendered pixels (see [accessibility-evidence.md](accessibility-evidence.md)).

## Spacing and rhythm

4 px base (`--space-unit`). Scale `--space-0 … --space-24` = 0, 4, 8, 12, 16, 20, 24, 32, 40, 48, 56, 64, 96 px. Section rhythm `--space-section` 64 px / `--space-section-lg` 96 px on desktop, 40 / 56 px below 768 px. Container `--size-public-max` 1200 px with `--size-gutter` 24 px (16 px mobile); workspace content 1360 px; reader 720 px; form column 480 px.

## Breakpoints

Mobile < 768, tablet 768–1279, desktop ≥ 1280, wide ≥ 1600 (`breakpoint` and `mediaQuery` exports; CSS modules use the literal queries). `useIsMobile()` returns the mobile match on the client and `false` on the server.

## What is not a token yet

Dark theme values, chart colours (no charts by decision), print styles for the magazine PDF (CNT-001).
