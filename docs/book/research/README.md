Where a note and the book differ, the book and its sources appendix are the edited result. The note shows what was found and why.

## Adding a note

Name it with the next free letter and a short topic (for example `I-topic.md`). Use this structure:

1. **Question.** What the note answers, and why it matters for Trustwork.
2. **Findings.** Each claim carries its source, with a link, title, publisher and year. Mark anything unverified as unverified.
3. **What it means for Trustwork.** The implications for the engine, a hub or the book. Use the status words exactly, and propose nothing as already built.
4. **Open questions.** What would change the conclusion, and who could answer it.

The [book's editorial rules](../README.md#editorial-rules) apply to notes as well: English only, no personal data, organisations named only for their public work (never as partners or "candidates"), and no quotations from private conversations.
